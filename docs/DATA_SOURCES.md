# 数据来源与真实性

## 原则

原创题目或合法授权题库；政府公告来源也需核对公开使用条款和 robots。禁止绕过登录、验证码、付费墙或速率限制。无授权数据时保持空库或明确 demo。

## 标记

demo=演示且不作为报考依据；pending=待核验；verified=经管理员核验（不代表官方授权）；expired=失效。来源保存 name/url/terms/fetchedAt/publishedAt/version/verification。正式岗位必须有有效官方 URL 和来源，人工核验资格条款。

## 接入流程

确认使用条件 → 建立 content_sources → 适配器输出标准 JSON → Zod 校验和去重 → 预览错误 → 事务导入为 pending → 人工比对公告附件 → 发布和记录审计。更新保存岗位历史，撤回信息标记失效而非静默改动。

## 开发数据

种子原创计算、逻辑、语言、资料题；虚构岗位与公告都写 demo，原文仅链接示例域名。不会默认导入任何第三方受保护题库。

## 后续适配器

统一 SourceAdapter 接口返回规范数据及来源元数据；首次上线仅手工/文件适配器。定时抓取须配置允许域名、最小间隔、重试上限及人工审核队列。未经核验不启动自动抓取。

## 专业

major_catalog 为可版本化目录，编码精确匹配、别名归一，不使用字符串包含判断资格。缺少目录、版本或模糊条款返回人工确认。
