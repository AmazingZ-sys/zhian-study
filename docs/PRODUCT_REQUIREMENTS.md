# 知岸公考 · 产品需求

## 定位

个人长期使用、可持续运营的公考学习与招考信息平台。简体中文，独立设计，不复制粉笔或公考雷达内容。

## 核心闭环

注册并设置目标 → 按章节练习 → 答题解析与错题复练 → 模拟考试与薄弱点复盘；设置报考资料 → 搜索岗位 → 条件核验 → 收藏对比 → 阅读官方公告。

## 用户和权限

游客可读已发布题目题干、岗位和公告；登录用户可保存学习记录与收藏，仅能读写自己的数据；管理员经服务端校验后维护内容。禁用用户和撤销会话立即失效。

## 功能范围

题型含单选、多选、判断；练习支持顺序、随机、分类、真题（有合法内容时）、错题与收藏。模拟考试答案持久化、服务端截止时间、报告；统计含每日、科目、连续学习、错题和成绩。岗位包含来源、条件、地区、时间及核验状态。管理支持内容 CRUD、JSON/CSV/XLSX 导入、错误报告和审计。

## 验收

每个可见操作必须连接 API 或明确标记未支持；禁止虚假人数、学习数据、招录信息。演示内容在列表和详情显式标识。导入全部通过才提交事务；失败不部分落库。考试提交不可重复记分。

## 非目标

第一阶段不开发 App/小程序 UI，不接入支付或盗取受版权保护题库。不承诺系统匹配代替官方资格审查。

## 运营前置条件

真实题库授权、岗位来源使用条件核查、隐私政策与保留周期确认、域名和生产基础设施配置。生产发布必须经过真实集成测试与恢复演练。
